Featured project

Fantasy League Almanac

An open-source desktop tool that turns an ESPN fantasy-baseball league's history into a browsable record book and Google workbook.

How the app works → View source and documentation

Local by default

League data is extracted to Parquet and DuckDB on the user's computer. The public workflow does not require a hosted warehouse account.

A narrow Google permission

The optional workbook flow requests only drive.file. It can work with the file the app creates, not browse the rest of a user's Drive.

Private before sharing

The app creates and renders the workbook privately. It asks immediately before enabling anyone-with-the-link viewer access.

What the project does not have

No hosted user accounts, advertising, analytics, payment collection, maintainer backend, or automatic upload of credentials, league data, logs, or workbook links.
